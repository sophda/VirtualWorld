# Virtual World — UE 5.7 可玩原型

依据上级目录的 `virtual world.md` 与 `guide.md`，本轮实现文档第 55 节的核心闭环：
**打工 → 买枪 → 招兵 → 地图占领 → 建国 → 勘探/修路/建厂 → 生产和税收 → 扩军**。

## 启动

打开 `vw_ue.uproject`，默认关卡为 `/Game/Maps/RiverValley`，点击 Play。
这是基于工程现有 ArchVis `SampleLevel` 制作的固定关卡。建筑、树木、草地、灯光、玩家、交互点与人物训练靶均已保存在地图中，未开始 Play 时也可查看和编辑。GameMode 不再生成环境模型。
原始 `/Game/ArchVis/SampleScene/SampleLevel` 与上一版 `/Game/Maps/ArchVisWorld` 保留供参考。

### 河谷地图

`RiverValley` 参考航拍图的空间布局：中心城镇和桥梁、蜿蜒河道、道路连接的住宅区、成片森林，以及外围山脊。主要地形约 1 公里见方，并有更远的背景地形延伸。场景是可编辑的原型美术布局，使用现有树木和建筑素材，以及保存为静态资产的地形、河道、桥梁和住宅模型。

大纲 `Valley/Terrain`、`Valley/River`、`Valley/Roads`、`Valley/Towns`、`Valley/Lighting` 分别管理对应内容。树林保存在植被实例中，可用 Foliage 模式修改。所有环境内容随关卡保存，运行时不重新生成。

M 地图使用中心战术区域的真实俯视底图，继续支持滚轮缩放、己方选择和右键攻击。当前战术指令仍覆盖原型中心约 110 米范围；外围山林主要用于场景纵深，尚未扩展经济格网、部队高度寻路或游泳系统。
建议使用至少 1000×650 的游戏视口，或全屏/新窗口运行。
测试区域有可见碰撞边界；角色意外掉到地面下方时会自动回到出生点，避免只看到天空和黑色背景。
当前实现为**单人原型**，远程/联机命令会被拒绝；尚未实现多玩家身份与状态复制。

## 操作

### 在编辑器中修改场景

1. 打开 `Content/Maps/RiverValley`，无需运行游戏即可看到整个场景。
2. 大纲 `Valley` 中是河谷地形、河流、道路、城镇和灯光；`ArchVis/OriginalScene` 保留原有中心建筑。可直接移动、旋转、缩放或替换材质。
3. `Gameplay/Player` 放置玩家 Manny 与出生点；`Gameplay/Training` 放置三个人物训练靶；`Gameplay/Services` 放置五个服务交互点。
4. `Content/Blueprints/BP_VWPlayer`、`BP_TrainingMannequin`、`BP_ServiceBeacon` 分别用于调整玩家、训练靶和服务点模型。服务点的 `Action` 与 `Display Label` 可在详情中设置。
5. `Gameplay/Navigation` 中的盒体仅用于战略小队绕障，不阻挡玩家走入建筑。修改场地范围或建筑位置后同步调整对应盒体；`VWNavigationObstacle` 标签用于识别障碍。
6. 场景改动保存关卡即可，不需要重新编译 C++。移动、射击、经济与运行时招募的小队仍由游戏逻辑驱动。
7. `Valley/Views/Overview_RiverValley` 是全景相机，可在大纲中右键驾驶该相机查看河谷全貌。更改地貌后，小地图静态底图需要重新捕获并更新 `World/Valley/Textures/T_ValleyTactical`。

| Shift | 冲刺 |

| J | 打工，个人收入 $150；8 秒冷却 |
| B | 花个人资金 $400 买步枪 |
| 左键（角色模式）/ R | 射击 / 装弹 |
| H | 花个人资金 $25 购买食物和备用弹药 |
| E | 在交互站附近 2.6 米内工作、购物或招募 |
| T | 招募一个 5 人小队，费用 $600 |
| N | 满足条件后建国 |
| 左键（地图） | 选择格子/该格小队 |
| 拖动左键（地图） | 框选多个小队 |
| 右键（地图） | 为选中小队下达机动/占领命令 |
| 右键红色敌军标记（地图） | 选中的己方小队接近目标并独立射击；右键空地取消显式攻击并移动 |
| 地图侧栏 | 勘探、建路、建矿/钢铁厂/工厂、捐款、购房、射击考试、图层开关 |
| F5 / F9 | 手动存档 / 读档 |

地图模式角色仍然留在世界中。地图的资源、军事、实控图层可独立开关。
玩家与小队共用 `UVWCombatComponent`，统一处理射击冷却、射程、命中遮挡、阵营过滤与伤害投递；玩家和小队通过各自的 `TakeDamage` 实现受伤行为。
每支小队有独立目标、射击计时与血量，100 点血量对应一名士兵，减员会减少模型数量和射速。进入射程且没有遮挡时射击；被建筑挡住时尝试绕路，不能隔墙命中。同阵营单位不会受到友军枪击伤害。
`ArchVisWorld` 的 `Gameplay/Enemies` 中已放置两组敌方测试部队（东侧、后方各 3 人），使用 `BP_EnemySquad`，编辑器中可调整位置和初始人数。
测试：按 T 招募两支小队 → M 打开地图 → 左键或框选己方标记 → 右键红色敌军标记。敌军会在接敌后还击；也可按 B 买枪，回到角色视角亲自射击敌军。
敌我小队血量、伤亡和攻击目标随 F5/F9 保存恢复；重新开始 Play 会重置测试敌军。当前仍为单人原型，小队伤害按整队血量聚合计算，尚无独立士兵 AI 或弹道物理模拟。
单位标记携带兵力数量，选中时显示目的地连线；边界显示交战相邻格的阵线。
交战中的格子显示虚线，战斗结束后更新实控方。隐藏军事图层时禁止部队选择和下令。

## 五分钟试玩路线

1. 初始个人账户 $2500，未建国，国库不存在。可按 J 打工。
2. 按 B 买枪，T 招募小队，M 打开地图。
3. 左键选择中心 `(0,0)` 的 5 人小队标记，右键东侧红色部落 `(2,0)`。
   小队按格推进，先占领 `(1,0)`，再与部落 3 名守军交战并占领。
4. 控制至少 3 格、拥有至少 5 名士兵、占领部落且个人资金至少 $1000 时，按 N 建国。
   系统创建独立国家 ID 和国库，将个人 $1000 作为启动资金转账至国库。
   玩家获得总统任职，已有领土和部队转为国家所有。
5. 在地图选择小队，右键北侧 `(0,1)`，获得煤矿所在土地。
6. 个人剩余 $500，可点击 Donate 显式转入国库；缺钱时按 J 工作。
7. 分别选择 `(1,0)`（铁）和 `(0,1)`（煤），各执行 Survey → Mine → Road。
8. 在 `(2,0)` 建 Steelworks 和 Road，在 `(0,0)` 建 Factory。
   每 10 秒一个模拟日。矿场每周期开采 4 单位；钢铁厂消耗 2 铁+1 煤，产出 2 钢；
   工厂消耗 2 钢，销售最终产品 $80，并缴纳 20%（$16）至国库。
   不连通首都道路的设施停产，资源储量会减少。
9. 按 F5 保存，继续操作后按 F9 恢复。存档包含账户、领土、部队、设施、库存、武器弹药、
   健康、住宅、技能、任职、角色位置及有界资金流水/事件记录。

个人模式可以射击训练靶，靶被击倒后 4 秒重置。累计击倒 3 个靶后，可在地图支付 $100
参加射击考试获得证书。住宅 $500。住宅和证书与个人身份绑定。
跌落伤害致死后角色回到出生点，个人资金/住宅/技能保留，总统任职撤销；
国家仍存在，但此原型尚无重新任命流程，失去任职后无法支出国库或指挥国家部队，可读档恢复。

## 架构与验证

- `VWDomainTypes.h`：稳定主体/账户 ID、领域命令、格网/小队状态、世界快照和资金流水。
- `VWDomainWorldSubsystem.cpp`：权威命令入口、权限/规则验证、建国、军事推进及领域事件。
- `VWEconomy.cpp`：整数最小货币单位、交易、配方生产、连通道路、最终产品 GDP 和税收。
- `VWPersistence.cpp` / `VWWorldSave.h`：USaveGame 快照，完整验证后原子替换世界状态。
- `VWPlayerController.cpp` / `VWHUD.cpp`：输入、UI 命令、选中 ID 和查询展示；UI 不直接修改领域状态。
- `VWCharacter.cpp`：视角、移动、射击/弹药、交互、跌落伤害。
- `VWGameMode.cpp`：读取关卡中带 `VWNavigationObstacle` 标签的障碍物，以及同步运行时小队/设施状态；不生成固定场景，不承担经济模拟。
- 经济/军事实体为数据。每个小队是 5 名士兵的聚合状态，不创建 5 个永久 Character。

UE 自动化测试路径为 `VirtualWorld.Domain`：
建国/国库隔离、生产/税收、存档往返/死亡/技能保留、非法命令/工资冷却/损坏存档。
报告位于 `Saved/AutomationReports/index.json`；在 Session Frontend 的 Automation 中可重新运行。

构建：
```powershell
& 'E:\Program Files\Epic Games\UE_5.7\Engine\Build\BatchFiles\Build.bat' vw_ueEditor Win64 Development '-Project=E:\MyProjects\VirtualWorld\vw_ue\vw_ue.uproject' -WaitMutex
```

## 当前范围与后续阶段

这是可玩灰盒，不是完整持续世界。部落战斗使用聚合守军消耗，尚无战术敌人 AI、战损/补给/寻路；
小队目前没有上级军事建制树。设施/道路使用简化格网与调试表现，没有正式美术资产。
工作为有冷却的抽象工作班次；GDP 为累计最终产品销售额，不是季度统计。
尚未接入 GAS、真正的 Enhanced Input 动态上下文、UMG/MVVM、World Partition 大世界、
区域划分/任命、铁路、合同、多人复制、MassEntity、数据库或大模型 API。
下一阶段宜继续完善军事建制/地区任命与战术 AI，再分离模块并接入联机身份与复制。

## Unreal MCP

地图鼠标操作：按 M 打开地图，滚轮放大后按住左键拖动浏览（全图比例限制平移，避免空白边缘）。按住右键拖框，松开后选择框内己方小队；右键单击己方小队可单选，单击空地向已选部队下达移动指令，单击红色敌军下达攻击指令。右键拖框不会发送移动或攻击命令；左键仍可点击侧栏按钮和选择区域。关闭地图会清除未结束的拖动状态。

### RiverValley 的 VSM 阴影开销

林区的 17,816 个树木实例使用 `/Game/World/Valley/Meshes/SM_ValleyOak`，启用 Nanite 和 Preserve Area（树叶面积保留），植被类型为 `/Game/Foliage/Auto_HillTree_02`。树木使用独立的材质副本，原 ArchVis 树模型保持原设置。地形、远山和城镇房屋也启用 Nanite，避免大量非 Nanite 模型占用 VSM 标记队列。保留虚拟阴影贴图和森林数量，不提高队列上限或隐藏告警。

手动检查：打开树木静态网格体，在 Nanite Settings 中确认 Enable Nanite Support 和 Preserve Area；Apply Changes 后保存。植被类型的 Mesh 应指向 `SM_ValleyOak`，组件 Forced LOD Model 为 0（自动）。打开 RiverValley 后分别在高空俯视和 Play 模式检查森林及阴影，查看 Output Log 是否新增 `[VSM]` 队列溢出警告。历史日志中的旧警告仍会保留。

现成 `McpAutomationBridge` 已用于检查项目、创建 Prototype 地图、关闭/重新启动前的检查、
运行 PIE、注入试玩输入和保存运行截图。本轮未修改桥接插件源码。
本地桥接令牌及 `Saved/` 输出不应提交到版本控制。

模型升级：使用 UE 官方 Manny 人物、步枪与 ArchVis 玻璃立面建筑，V 切换视角；素材路径和许可说明见 ASSET_SOURCES.md。

小队模型：T 招募后显示 5 名持枪 Manny，分队形站立；位置随战略命令更新并播放移动/待机动画。读取存档会重建小队显示，人数按 Soldiers 同步，模型目前为表现层，不具备独立士兵寻路或碰撞。

场景尺度校准：人物和小队模型保持原始尺寸；ArchVis 三层建筑本体统一缩放到9.9米高（每层约3.3米），移除模板草坪底座；路灯6米、展亭3.6米、花坛0.45米。射击靶保持1.6米高并贴地，终端保持1.4米高。建筑之间重新留出活动空间。

连续地图与寻路：M 地图不再显示方格；左键点击小队圆点或拖框选择，右键点击任意空地可下令，显示实际绕障路线。小队按世界坐标移动，允许斜走；建筑、展亭、路灯、花坛、终端和靶标按285厘米队形净空参与路线规划，封闭或障碍内部的目标会拒绝。领地/生产仍使用后台区域数据；旧存档会迁移到连续位置。当前为静态障碍整体队形寻路，尚无单兵自主绕行和小队之间的动态避让。
